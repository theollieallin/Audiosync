Ever come back from a shoot with 50 video clips, 20 WAV files and absolutely no idea which audio belongs to what? AudioSync takes the faff out of syncing separate audio recordings to your footage. ⬇ Download Here 📖 Installation Guide

Get Started In 4 Steps

① Install Python

brew install python

② Install FFmpeg

brew install ffmpeg

③ Install NumPy

python3 -m pip install numpy

④ Run AudioSync

python3 audiosync.py "/Your/Folder"
